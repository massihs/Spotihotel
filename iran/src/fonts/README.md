# Fonts

- `persian-digits.woff2`: numbers only, cut from **Estedad** (variable, weights 100–900): 0–9 drawn
  as ۰–۹ and % as ٪, with the Persian/Arabic digits and separators; its tabular figures (`tnum`)
  apply to the digits only, so the thousands separator ٬ stays narrow in aligned columns. Placed
  first in the Persian font stack, every number on a Persian page renders in Persian whatever
  produced it. A modified version of Estedad, renamed "Spotihotel Digits"; SIL Open Font License
  1.1 (`OFL-Estedad.txt`).
